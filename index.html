licode

用 Go 编写的 AI 编程助手，单二进制、静态编译、跨平台。浏览器打开即用，手机/电脑均可使用。

查看文档 下载二进制
终端
$ ./licode --host 0.0.0.0 --port 8080
licode serve 已启动: http://0.0.0.0:8080/

核心功能

🤖

多 AI 提供商

OpenAI / Claude / Ollama / Gemini 一键切换，均用各自原生接口

🔧

工具调用

读写文件、代码搜索、Shell 执行，Agent 自主调用并回填结果

🧠

子代理系统

explorer / builder / planner，DAG 依赖并行调度

💬

多对话

会话列表、自动标题、切换、删除、实时保存到磁盘

🔍

联网搜索

自建多引擎搜索 + 本地倒排索引（BM25 + 中文 bigram 分词）

🛡️

代码审计

12 类静态规则 + LLM 深度分析，一键修复并自动备份

📦

扩展能力

MCP 接入、Skills 技能、WASM 插件、外部工具热加载

🌐

离线前端

Nuxt 3 静态打包进二进制，零 CDN 依赖，内网开箱即用

架构概览

前端层
浏览器 / 手机 Nuxt 3 SPA WebSocket
↓
服务层
HTTP 路由 WebSocket Hub 登录认证 文件管理
↓
Agent 层
主 Agent 循环 工具注册表 子代理调度器 上下文压缩
↓
AI 层
OpenAI Claude Ollama Gemini

快速开始

1

下载

wget https://github.com/li63050a/licode/releases/latest/download/licode-linux-amd64
chmod +x licode-linux-amd64 && mv licode-linux-amd64 licode
2

启动

./licode --host 0.0.0.0 --port 8080 --password mypass
3

使用

浏览器打开 http://your-ip:8080
在「设置」里配置 AI 提供商 API Key
开始提问即可
