## 恢复内容

- 顶部状态栏：licode [BUILD/PLAN] N sessions
- 颜色区分：用户蓝色、AI 粉色、工具黄色、错误红色
- 斜杠命令菜单：/new /delete /branch /clear /sessions /set /plan /build /help
- Tab 切换 Build/PLAN（底部状态提示 5 秒）
- 设置面板：含 PLAN 禁用工具配置（默认禁用 Write,Edit,Delete,Move,Bash,Shell）
- Ctrl+C 连按两次退出
