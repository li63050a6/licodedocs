## 改进
- **顶部状态栏**：licode | BUILD/PLAN | N sessions
- **Tab 切换模式后显示详细提示**（5秒自动消失）
- BUILD：可执行工具（读写文件、运行命令）
- PLAN：仅思考，不执行工具（安全预览）
- 整体布局优化

## 快捷键
| 按键 | 功能 |
|------|------|
| `/` | 打开命令菜单 |
| Tab | 切换 BUILD/PLAN 模式 |
| Ctrl+C | 停止/退出 |
| 上下键 | 历史翻动/菜单选择 |
| Enter | 发送/确认 |
